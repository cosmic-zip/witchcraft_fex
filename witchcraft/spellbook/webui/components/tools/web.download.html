web.download Downloads a full webpage or open directory recursively, including all necessary resources (images, CSS, JS) for offline viewing. It only downloads content at and below the specified URL, without mirroring the entire site. Supports polite scraping with adjustable wait times, optional rate limits, and retries while preserving existing files.
